Vice City Cover — an offline web app that turns a photo and a caption into GTA 6-style multi-panel cover art. A large hero panel plus two smaller panels, a Vice City sunset/neon colour grade, bold condensed caption lettering, and PNG export in 1080×1080, 1080×1350 and 1920×1080 post sizes. Load a photo (or use the two sample photos), crop and reposition it per panel, edit the caption, pick a size, export a PNG.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
